# 计划与限制

以下为候选方向，不代表已实现或确定排期。

## 优先验证

- [ ] 全新 Windows 环境安装与启动。
- [ ] 直播伴侣画面、绿幕和声音收录。
- [ ] 许可明确且可维护的抖音连接器与真实进房验证。
- [ ] 网络中断、长时间运行和连续多人进房。

## 可用性

- [ ] 欢迎词、音色和冷却设置界面。
- [ ] 服务停止入口与连接器状态。
- [ ] 有授权的自定义 Live2D 模型切换。
- [ ] 播放确认、过期提示及多窗口交接。

## 工程维护

- [ ] 资产哈希和安装完整性校验。
- [ ] UI 测试服务隔离，避免干扰用户窗口。
- [x] 分享链接、欢迎队列和播放租约的单元测试。
- [ ] 扩充 API、断线重连与真实进房测试。

AI 聊天、主播语音识别、礼物运营和无人值守直播不在当前版本范围内。
